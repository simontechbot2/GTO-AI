# GTO AI

GTO AI is a multi-provider AI web application with a ChatGPT-style interface.

## Features

- AI conversations
- Multiple AI providers
- Automatic provider routing
- Conversation history
- Model selection
- File uploads
- Web-search integration point
- Admin dashboard
- User management
- Rate limiting
- Secure server-side API keys
- Dark mode
- Responsive mobile interface

## Architecture

The frontend can be deployed to GitHub Pages.

The backend must be deployed separately because GitHub Pages cannot run Node.js server code.

Never put private AI API keys inside frontend JavaScript.
